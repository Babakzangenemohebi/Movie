# سینه‌فیل وایب‌فارسی (Cinephile VibeFarsi Platform)

پلتفرم جامع تحلیل، آرشیو و تماشای آنلاین فیلم و سریال برای عاشقان سینما (ترکیبی از اتمسفر هنری **MUBI**، امکانات تحلیلی **Letterboxd** و موتور استریم مستقیم **FrameXTV**).

## ویژگی‌های کلیدی
- **راست‌چین (RTL) و بومی‌سازی کامل:** فونت وزیرمتن، تبدیل تمام اعداد و امتیازها به فارسی، نمایش تاریخ اکران به شمسی و میلادی.
- **موتور استریم FrameXTV:** پشتیبانی از فیلم و سریال، انتخابگر سرور (`auto`, `barbarian`, `archer`, `goblin`) و ذخیره خودکار تایم‌لاین تماشا با `postMessage`.
- **بدون داده فیک (Zero Mock Data):** اتصال مستقیم به TMDB API + فال‌بک خودکار به API زنده عمومی (TVMaze) برای اجرای فوری بدون خطا.
- **دفترچه خاطرات سینمایی (Film Diary):** مجهز به انتخابگر تقویم شمسی وایب‌فارسی، ثبت امتیاز ستاره‌ای و یادداشت‌های تحلیلی.

## راهنمای نصب و اجرا

۱. ابتدا فایل زیپ را استخراج (Extract) کرده و وارد پوشه پروژه شوید:
```bash
cd cinephile-vibefarsi-app
```

۲. پکیج‌ها را نصب کنید:
```bash
npm install
```

۳. (اختیاری) فایل `.env.example` را به `.env.local` تغییر نام دهید و کلید رایگان TMDB خود را در آن قرار دهید (یا مستقیماً از داخل دکمه «تنظیم کلید TMDB» در بالای سایت وارد کنید).

۴. سرور توسعه را اجرا کنید:
```bash
npm run dev
```

۵. مرورگر خود را باز کرده و به آدرس زیر بروید:
`http://localhost:3000`
